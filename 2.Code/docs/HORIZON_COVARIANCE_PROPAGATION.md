# Native horizon covariance propagation

Stage 3 propagates the posterior beliefs produced by Stage 2 over every point
of the native NMPC prediction horizon. It does not yet change the NMPC
constraint; the resulting covariance is evidence and the input to Stage 4
chance-constraint tightening.

## State conventions

Vehicle nominal state:

```text
x = [p_world, v_world, q_wxyz, omega_body] ∈ R13
```

Vehicle local error and covariance:

```text
δx = [δp, δv, δtheta, δω] ∈ R12
P_x ∈ R12x12
```

Obstacle tracker state and covariance:

```text
x_o = [p_o, v_o] ∈ R6
P_o ∈ R6x6
```

The first item in each returned horizon is the current posterior covariance:

```text
P_x[0] = VehicleBelief.error_covariance_12
P_o[0,j] = ObstacleBelief[j].covariance_6
```

## Vehicle propagation

`quadrotor_mpc/control/nmpc/covariance.py` derives the continuous local-error Jacobians from the
same rigid-body equations used by the native ESEKF, then applies the real-time
first-order discretization:

```text
A_d[k] = I + dt A_cont[k]
B_d[k] = dt B_cont[k]
```

The attitude blocks follow the right-multiplicative quaternion error used by
Stage 2. No redundant 13x13 quaternion covariance is introduced. A slower RK4
finite-difference linearization remains available as a verification mode.

Open-loop mode uses:

```text
P_x[k+1] = A[k] P_x[k] A[k]^T + Q_x
```

`A[k]` is the discrete error-state Jacobian around the optimized nominal state
and input at step `k`. `Q_x` is generated by independent white linear and
angular acceleration disturbances, including the position/velocity and
attitude/angular-rate cross terms from discrete integration.

Optional `feedback_lqr` mode computes finite-horizon local gains backwards:

```text
u = u_nominal + K[k] δx
A_cl[k] = A[k] + B[k] K[k]
P_x[k+1] = A_cl[k] P_x[k] A_cl[k]^T + Q_x
```

This is a local covariance approximation. It does not replace the nonlinear
NMPC command and does not claim an LQR controller is applied to MuJoCo.

## Obstacle propagation

Every obstacle uses the tracker constant-velocity model:

```text
F_o = [[I, dt I],
       [0,    I]]

P_o[k+1] = F_o P_o[k] F_o^T + Q_o
```

`Q_o` is the exact discrete covariance for piecewise-constant white
acceleration over one controller interval. Means and covariances therefore
share the same 6D tracker model, while configured truth motion remains outside
the controller.

## Configuration

Stage 3 is enabled in `config/mujoco_native_estimation.yaml`:

```yaml
controller:
  covariance_propagation:
    enabled: true
    mode: open_loop
    linearization: analytic_first_order
    acceleration_process_std_mps2: 0.35
    angular_acceleration_process_std_radps2: 0.60
    obstacle_acceleration_process_std_mps2: 0.50
    finite_difference_epsilon: 1.0e-6
    minimum_covariance_eigenvalue: 1.0e-12
```

The exact deterministic scenarios explicitly keep propagation disabled to
preserve their Stage 1 regression schema and zero-covariance baseline.

## Runtime and recording shapes

| Value | Shape |
|---|---:|
| vehicle covariance horizon | `(N+1, 12, 12)` |
| obstacle covariance horizon | `(N+1, n_obs, 6, 6)` |
| position covariance slice | `(N+1, 3, 3)` |

Each native recording stores:

```text
predicted_error_covariance_horizon
predicted_obstacle_covariance_horizon
```

Telemetry also exposes terminal and maximum position standard deviations over
the horizon. The native safety plot shows the largest terminal-axis position
sigma as a dashed curve. Replay accepts both Stage 3 recordings and older
bundles that do not contain these arrays.

## Numerical safeguards and validation

After every prediction, covariance is symmetrized and projected to a configured
minimum eigenvalue. Tests verify:

- the first horizon covariance equals the current belief;
- analytic first-order Jacobians agree with RK4 finite differences at hover;
- expected horizon dimensions;
- symmetry and positive semidefiniteness;
- trace and position-variance growth for the open-loop hover case;
- the obstacle one-step result equals `F P F^T + Q`;
- feedback-aware propagation differs from open-loop and remains PSD;
- configuration and numeric recording round trips.

Stage 3 does not establish a collision-probability guarantee. Stage 4 must
combine the vehicle position covariance and obstacle position covariance,
project relative uncertainty onto the collision normal, allocate risk and
actually tighten the native NMPC constraint.
